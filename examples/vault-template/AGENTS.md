# 知识库规则（AGENTS.md）

> 豆包工作维护本库时必须遵守的规则。

## 目录结构
- `Raw Sources/`：原始摄入存档（逐字稿/提取内容），文件命名 `<日期>-<主题>.md`
- `Wiki/`：AI 维护的总结/概念页，用双括号 `[[链接]]` 互连
- `index.md`：全库目录（AI 提问前先读这里）
- `log.md`：操作日志（追加式，最新在上）

## 规则
- 先结果后依据；数字/统计须可验证
- 不编造内容；截断/受限时标「待补充」
- 保留用户已有改动，不覆盖无关工作
- 敏感信息（证照/密码/家庭住址/资产）拒绝入库
- 每次摄入/更新写 `log.md`，页面增减同步 `index.md`
